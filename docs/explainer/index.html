What is vault-graphrag-paywall and what is it like to use?

Long image

A

Answer

It is a local Python prototype of pay-per-query search over Obsidian notes. You fund a wallet, ask a question, and get back linked notes plus a signed $0.05 receipt.

  1. You run it as a command-line tool (vault-paywall) or import it as a Python library; it needs no API keys and no network.1
  2. A query searches your notes by keywords, then follows [[wikilinks]] up to two hops to collect related notes.2
  3. Each query takes $0.05 from an in-memory wallet and returns an HMAC-SHA256 signed receipt.3
  4. The stablecoin payments, homelab VMs and web service are modelled as data only: nothing is charged, deployed or served.

What does one query look like from your side?

Diagram structure
  • You (terminal) you
  • Wallet ledger wallet
  • Note graph vault
  • you → wallet · Mint $0.50 → 10 tokens
  • you → wallet · Ask a question
  • wallet → you · Refuse if under $0.05
  • wallet → vault · Charge $0.05, then search
  • vault → you · Linked notes + summary
  • wallet → you · Signed receipt, $0.45 left
  1. Mint $0.50 → 10 tokens ↗

    vending-mint turns a USD amount into tokens at $0.05 each. No money moves; the balance lives in memory.

  2. Ask a question ↗

    query --query "..." takes plain text. The CLI funds the wallet itself with --usd (default $0.50).

  3. Refuse if under $0.05 ↗

    An empty wallet raises InsufficientBalanceError and no search runs.

  4. Charge $0.05, then search ↗

    Notes that share query words become seeds; wikilinks pull in neighbours up to --hops.

  5. Linked notes + summary ↗

    You get the notes, their tags, apps and paper IDs, and a templated summary line.

  6. Signed receipt, $0.45 left ↗

    The receipt holds a SHA-256 hash of the question and an HMAC signature that verify_receipt can check.

What do you type, and what comes back?

CommandYou giveYou get back
indexNothing, or --vault-dirNote, link, tag and paper counts as JSON
vending-mintWallet ID and USD amountTokens minted and the new balance
queryWallet, question, hopsMatching notes, summary text, signed receipt
homelab-specBusiness ID, storage GB, portsA VM spec and a Docker Compose file as text
import-trajectoryAn agent transcript fileRedacted Markdown notes linked into the graph
demoNothingAll of the above in one JSON document

Each command starts from an empty wallet

The ledger is a Python dictionary, so a wallet minted by vending-mint is gone when that command exits. Use query --usd to fund the wallet in the same run, or call the Python API in one process.
